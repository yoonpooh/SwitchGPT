# SwitchGPT

[English](README.md) · [한국어](README.ko.md) · **日本語** · [简体中文](README.zh-CN.md)

**ChatGPT デスクトップアプリ**のアカウントを切り替える、軽量な macOS メニューバーアプリです。

コンパクトなパネルからアカウントの保存、残りの使用量の確認、アカウントの切り替えができます。SwitchGPT は独立したユーティリティであり、OpenAI と提携しておらず、OpenAI の承認を受けた製品でもありません。

[最新リリースをダウンロード](https://github.com/yoonpooh/SwitchGPT/releases/latest)

## 機能

- 現在の ChatGPT セッションを変更せずに、ブラウザでログインしてアカウントを追加します。
- ログイン情報を macOS キーチェーンに保存します。
- メールアドレスとプランのバッジを表示します。
- サービスから返された利用枠、残りの割合、リセット時刻を表示します。
- 利用可能なリセット回数と最も近い有効期限を表示します。日付にポインタを合わせると時刻も確認できます。
- 確認後にアカウントを切り替えます。この処理では ChatGPT とローカルのバックグラウンドサーバーが再起動します。
- カードのドラッグでアカウントを並べ替えられます。現在のアカウントは枠線で強調されます。
- ライト／ダークモードに対応するメニューバーアイコンを使用します。
- Mac の優先言語に従って英語、韓国語、中国語（簡体字）、日本語を表示します。それ以外の言語は英語になります。このリリースでは中国語の他の地域・文字体系も簡体字で表示します。
- 日付は選択された言語の形式と Mac のタイムゾーンに従います。

## 動作要件

- macOS 14 以降。
- ダウンロード用の `arm64` ビルドは Apple シリコン搭載 Mac 向けです。このリリースには Intel ビルドを含めておらず、動作確認も行っていません。
- 現在の ChatGPT デスクトップアプリがインストールされ、ログイン済みであること。
- 標準のファイル形式の認証情報保存先 `~/.codex/auth.json` を使用していること。

SwitchGPT は Chat、Work、Codex を統合した現在の ChatGPT デスクトップアプリを対象としています（[OpenAI のドキュメント](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)）。既存のバンドル識別子 `com.openai.codex` でアプリを検出し、同梱の CLI を使用するため、CLI を別途インストールする必要はありません。ブラウザのセッションは変更しません。

## インストール

1. [リリース](https://github.com/yoonpooh/SwitchGPT/releases)から `SwitchGPT-v0.1.3-macos-arm64.zip` をダウンロードします。
2. ZIP を展開し、**SwitchGPT.app** を **アプリケーション** フォルダに移動します。
3. アプリを開きます。メニューバーに双方向の矢印アイコンが表示されます。通常のウインドウや Dock アイコンはありません。
4. メニューバーアイコンをクリックし、**アカウントを追加**を選んでブラウザでのログインを完了します。

### ChatGPT にインストールを依頼する

ローカルファイルとターミナルのツールを利用できる ChatGPT セッションに、次のプロンプトを貼り付けてください。

```text
https://github.com/yoonpooh/SwitchGPT から最新の SwitchGPT リリースをこの Mac にインストールしてください。この Mac がリリースの動作要件を満たすことを確認し、アプリの ZIP と公開されている SHA256SUMS.txt をダウンロードして、インストール前にチェックサムを検証してください。実行中の SwitchGPT があれば終了し、/Applications にインストールして開いてください。保存済みアカウントとキーチェーン項目はすべて保持してください。ログインやアカウントの切り替えを代行しないでください。macOS が初回起動をブロックした場合は、システムのセキュリティ設定を無効にせず、Apple のアプリ単位の「このまま開く」手順を案内してください。
```

ローカルツールを利用できない場合は、上記の手動インストール手順を使用してください。

### 初回起動

配布版は **ad-hoc 署名**を使用しており、**Apple による公証は受けていません**。macOS が起動をブロックした場合は、意図したリリースをダウンロードしたことを確認してアプリを開こうとした後、選択肢が表示されれば **システム設定 → プライバシーとセキュリティ → このまま開く**を使用してください。[提供元が不明なアプリを開く Apple の手順](https://support.apple.com/en-ca/guide/mac-help/mh40616/mac)を参照してください。組織が管理する Mac では、この例外許可が制限される場合があります。

リリースには `SHA256SUMS.txt` も含まれます。両方のファイルを同じフォルダに置き、次のコマンドでアーカイブを検証できます。

```sh
shasum -a 256 -c SHA256SUMS.txt
```

### アップデート

メニューバーパネルから SwitchGPT を終了し、アプリケーションフォルダ内のアプリを新しいバージョンに置き換えてから開き直してください。アカウント一覧とキーチェーン項目は、アプリバンドルの外に保存されています。

## 使い方

1. **アカウントを追加：** 保存したいアカウントごとにブラウザでログインします。メールアドレスはログイン情報から読み取ります。
2. **更新：** 更新ボタンで現在の使用量とリセットの利用可能回数を取得します。
3. **切り替え：** 実行中の ChatGPT の作業を終了し、別のアカウントのカードをクリックして再起動を確認します。現在のアカウントをクリックしても切り替えません。
4. **並べ替え：** カードを別のカードへドラッグして保存順を変更します。
5. **削除：** ゴミ箱アイコンをクリックし、保存リストからの削除を確認します。OpenAI アカウント自体は削除されません。

利用枠リセットの欄は**表示専用**です。SwitchGPT はリセットを実行・消費しません。

言語の変更はアプリを開き直すと反映されます。アプリ内の言語選択メニューはありません。

## ソースからビルド

Swift 6 と macOS SDK を含む Xcode をインストールし、そのコマンドラインツールを選択してから実行してください。

```sh
git clone https://github.com/yoonpooh/SwitchGPT.git
cd SwitchGPT
./script/build_and_run.sh --verify
```

`dist/SwitchGPT.app` にアプリをビルドし、ad-hoc 署名を行って起動し、プロセスの実行を確認します。アプリケーションフォルダには自動インストールしません。自分でビルドしたアプリをインストールする場合は、SwitchGPT を終了し、Finder で生成されたアプリをアプリケーションフォルダに移動してください。

利用できるコマンド：

```sh
./script/build_and_run.sh           # デバッグ版をビルドして起動
./script/build_and_run.sh --verify  # ビルド・起動後にプロセスを確認
./script/build_and_run.sh --build   # 起動せずにデバッグ版をビルド
./script/build_and_run.sh --release # 起動せずに最適化版をビルド
swift test                         # テストを実行
```

可能であれば、リポジトリは iCloud Drive の外に置いてください。同期フォルダで Finder 情報やリソースフォークに関するコード署名エラーが発生した場合は、別のビルドディレクトリでテストしてください。

```sh
swift test --scratch-path /tmp/switchgpt-tests
```

### リリースのパッケージ化

スクリプトはビルドを実行する Mac のアーキテクチャ向けにビルドします。公開済みの v0.1.3 は Apple シリコン向けです。

```sh
./script/build_and_run.sh --release
ditto -c -k --norsrc --keepParent dist/SwitchGPT.app dist/SwitchGPT-v0.1.3-macos-arm64.zip
(cd dist && shasum -a 256 SwitchGPT-v0.1.3-macos-arm64.zip > SHA256SUMS.txt)
```

## データと互換性

| データ | 保存先 |
| --- | --- |
| 保存済みのログイン情報 | macOS キーチェーン（SwitchGPT が管理） |
| アカウント一覧と順序 | `~/Library/Application Support/SwitchGPT/accounts.json` |
| 現在のデスクトップ認証情報 | `~/.codex/auth.json` |

0.1.3 では、新しいアカウント一覧が存在しない場合、初回起動時に以前の保存先から一覧をコピーします。元のファイルと既存のキーチェーン項目は保持します。

切り替え前に現在の認証情報を保存し、権限 `0600` の一時ファイルを使用して有効な認証ファイルを置き換えます。ChatGPT の再起動に失敗すると、以前の認証情報の復元を試み、復元の失敗も表示します。

使用量は OpenAI の非公開エンドポイント `chatgpt.com/backend-api/wham/` から直接取得します。SwitchGPT 独自のバックエンドはありません。エンドポイントやデスクトップアプリのローカルサーバーの動作は変更される可能性があり、認証情報が期限切れになると再ログインが必要になる場合があります。ローカルでの再起動成功だけでは、サーバーが新しいセッションを受け入れたことを確認できません。

現在の制限：

- API キー認証、keyring/auto 形式の認証情報保存、独自の `CODEX_HOME`、リモートホストには対応していません。
- 自動アカウント切り替えや内蔵アップデーターはありません。
- 切り替えは、デスクトップアプリのローカルサーバーを共有する CLI セッションにも影響する場合があります。実行中の作業を先に終了してください。
- 使用量や有効期限の情報がない場合は、ゼロではなく取得不可として表示します。
- ビルドの成功は、すべての ChatGPT デスクトップ版や対応 macOS バージョンとの互換性を保証するものではありません。

Issue やコミットには、認証情報、アカウント一覧、個人のアカウントが映ったスクリーンショットを含めないでください。

## ソース構成

```text
Assets/                         アプリとメニューバーのアイコン
Sources/SwitchGPT/
  App/                          メニューバーアプリのエントリーポイント
  Models/                       アカウント・使用量モデルと多言語処理
  Resources/                    英語・韓国語・中国語・日本語の文字列
  Services/                     ログイン・キーチェーン・使用量・セッション処理
  Stores/                       アカウントの状態と順序
  Views/                        アカウントパネルと使用量表示
Tests/SwitchGPTTests/   認証・ログイン・サーバー・順序・多言語テスト
script/build_and_run.sh          ビルドとアプリのパッケージ化
```

テストにはダミーの認証情報と一時ファイルを使用します。実際のアカウント切り替えや利用枠リセットの消費は行いません。実際の認証とサーバー互換性は別途確認する必要があります。
